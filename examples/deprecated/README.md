# Deprecated Win32 `WM_COPYDATA` Examples

These examples demonstrate legacy `WM_COPYDATA` (`5000`–`5010`) and shared-memory (`5006`) IPC calls retained in Seer for backward compatibility with existing third-party integrations.

For all new integrations, use the current examples in the parent [`examples/`](../) directory (Named Pipe JSON-RPC 2.0 and dynamic `4002`/`4003` explorer registration).
