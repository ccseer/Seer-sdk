# Legacy Win32 `WM_COPYDATA` Examples

These examples demonstrate legacy `WM_COPYDATA` (`5000`–`5010`) and shared-memory (`5006`) IPC calls, which remain fully supported for existing and lightweight third-party integrations.

For richer session control, state queries, viewer switching, and event subscriptions, see the Named Pipe JSON-RPC 2.0 and dynamic `4002`/`4003` explorer registration examples in the parent [`examples/`](../) directory.
